# ФОРМА

Платформа для мебельщиков: замер → спецификация → визуализация → чертежи →
техпакет со сметой. Одно приложение вместо связки «рулетка, блокнот, Excel
и сосед, который умеет в 3D».

Работает офлайн: съёмка, параметры, визуализация и чертежи считаются прямо
в браузере. Сервер добавляет то, чего в браузере быть не может, — общий
каталог компании, неизменяемые ревизии проектов, роли сотрудников, деньги
и ключи провайдеров.

## Что умеет

Восемь категорий изделий: кухня, шкаф, тумба, ТВ-зона, стенка в гостиную,
прихожая, мебель для ванной, стеллаж. Для каждой считается раскладка модулей,
из неё выводятся визуализация, чертежи, спецификация, ведомость крепежа и
смета — из одного источника, поэтому цифра на картинке и цифра в раскрое
совпадают по построению.

Визуализация считается собственным трассировщиком лучей в браузере: мягкие
тени, отражения, шумоподавление, проявка кадра. Три варианта снимаются
с трёх ракурсов — фронтально и в две четверти.

Кухню можно вписать в фотографию помещения: приложение разбирает снимок,
решает камеру, снимает прежнюю мебель и ставит на её место новую.

Замеры вводятся текстом как есть — «задняя стена 3200, холодильник 600», —
разбор находит числа и показывает, что понял. Записывается только то, что
подтвердил человек: по этим числам режут материал.

## Запуск

Нужен Node 24 или новее — используются встроенные `node:sqlite` и запуск
TypeScript без сборки.

```
cd backend  && npm install && npm run seed && npm run dev
cd frontend && npm install && npm run dev
```

Сервер поднимется на `http://localhost:8787`, приложение — на
`http://localhost:5173`. Демо-вход: `demo@forma.ru` / `demo12345`.

Без сервера приложение тоже работает — откроется в автономном режиме.

## Проверки

```
cd backend  && npm test          # 74 интеграционных теста API
cd frontend && npm test          # расчёты, раскладки, сцены, вписывание в фото
cd frontend && npm run typecheck && npm run build
```

## Устройство

```
frontend/   React 19 + Vite 8 + Tailwind 4; трассировщик, чертежи, экраны
backend/    node:http + node:sqlite, без веб-фреймворка; API, деньги, файлы
shared/     домен на Zod: спецификация, каталог, роли, кредиты, смета
mobile/     Expo-обёртка (WebView) для установки на телефон
AUDIT.md    аудит против ТЗ и план миграции M0–M7 — все этапы закрыты
```

Правила, из которых следует остальное: спецификация проекта — единственный
источник правды, картинка источником размеров быть не может; согласованная
ревизия неизменяема; деньги везде целыми копейками; ключи провайдеров живут
только в памяти сервера и во фронтенд не попадают.

## Провайдер изображений

Без ключа работает встроенный тестовый провайдер, а изображения считает
локальный трассировщик — кредиты при этом не тратятся. С ключом генерация
уходит на сервер: он резервирует кредиты, ставит задание в очередь и
обращается к провайдеру.

Ключ задаётся в `backend/.env` (образец — `backend/.env.example`) и наружу
не выдаётся ни при каких условиях. Глобальный выключатель
`AI_GENERATION_ENABLED=false` останавливает новые запуски, не ломая проекты,
расчёты и чертежи.

## Чего пока нет

Сквозных браузерных тестов; своей геометрии у категории «другое изделие»;
вписывания в фотографию для всего, кроме кухни — разбор снимка построен на
линиях пола и столешницы. Очередь заданий живёт в том же процессе, что и API:
для одной машины этого достаточно, для многих компаний её придётся вынести.
